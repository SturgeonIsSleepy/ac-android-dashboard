## 防烧屏

纯黑背景，九个像素位置，每 30 秒小幅移动，最大横纵位移各四个物理像素。实际诊断记录包含多种 shift 值，触摸映射使用同一偏移

暂停或断线且一分钟未触摸后触发 dim，触摸或恢复实时数据后恢复。除窗口亮度申请外，应用内变暗层保证外屏像素亮度下降，避免依赖厂商对副屏窗口亮度的支持。正常驾驶不自动变暗

最终外屏截图已确认整个画面实际变暗。诊断为 `status=259 dim=true shift=-4,4`；触摸后同一暂停流为 `dim=false`，恢复实时流后为 `status=258 dim=false`。这组为明确标记的合成流，真实游戏暂停状态也观测到 `status=3 dim=true`

防烧屏只降低风险，本次没有长期 OLED 老化测试，不能保证完全避免烧屏

## 连接与检查

生产桥接两次捕获为 60.00 Hz 与 59.33 Hz，帧间隔中位数 16 ms，本地回环无序号跳帧。真实外屏前台绘制约 59.8 次每秒，手机 RTT 多次约 7–16 ms，重连期间有 58 ms 的短时读数。RTT 和接收到绘制的间隔不代表完整游戏到屏幕发光延迟

反复切换路书测试时曾出现距离文字缺失，去掉强制缓存的 View 硬件图层后，使用系统默认硬件绘制，所有重复场景的距离与计时底板重新核实为完整显示

Android 构建与 lint 通过。真实 412 字节 C# 包通过 Android 解码，旧 268 和 344 字节帧兼容检查通过。可变分段、缺失分段、完圈停留、参考配色、会话重置、磨损反向量，以及防烧屏状态逻辑通过检查

桌面继续采用可见连接监视终端。测试结束后恢复生产桥接，没有新增后台服务或放宽防火墙。当前为调试签名，仅当前设备、经典版 AC 和 Monza 实测
