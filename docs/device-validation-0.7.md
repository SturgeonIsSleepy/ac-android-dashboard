# 0.7 实机验证

日期：2026-10-08

vivo X Flip V2256A，Android 14，外屏 display 1，682 × 422，原生 Android Canvas

## 设置按钮修复

用户确认问题发生在返回、恢复默认等文字按钮。原生 Material 按钮的默认背景内缩、内边距和最小高度与外屏短行高不匹配，导致文字被裁切。修复改用明确内边距、居中单行文字及圆角原生涟漪背景，取消默认最小高度和字体填充，返回及恢复默认高度为 40 dp

真实外屏逐页检查首页、转速页、图库、连接页和 IP 弹窗。原始 PNG 中每个按钮的文字像素均在按钮边界内，有至少 5 像素余量，汉字高度至少 20 像素。返回、恢复默认、取消、连接均检查。测试没有执行恢复默认或修改 IP，用户的 6650 推荐转速、地址与样式保持一致

按钮原始截图和边界报告保存在 artifacts/buttons-0.6.1；最后一次记录来自 0.7 最终功能构建，按钮实现相同

## 最终参考图

引用聊天接口只返回文字，浏览器读取超时。用户随后直接提供最终图片。新增独立“参考图复刻”选项，为第十种样式，原来的汽车计时仪表继续保留

按图片复刻黑底、细蓝框、蓝灰标题、大号白色直立计时、左侧最佳圈与红绿圈差、右侧汽车轮廓和四轮磨损、底部赛道状况与燃油。调整上下分区比例，在 682 × 422 中为底部信息保留足够高度，增加路温和抓地力可读性。没有加入实物支架、挡风玻璃或手机壳

轮胎保留用户早先指定的 0% 新胎、100% 磨尽语义，色条由绿到黄、橙、红。参考图的示例百分比不写入实际游戏；胎温异常仍只写 cold/hot，正常省略。布局使用图中英文标签，保留连续防烧屏微移和自动维修区覆盖

## 实际数据

只读 CSP 原生 API 的 roadGrip、rainWetness、rainWater、fuelPerLap 经已有采集脚本传输，RoadTemp 直接读取经典 AC 共享内存。当前 Monza/Maserati 会话真实路温约 29.13°C，抓地力 1.0，湿度 0，积水 0，原生每圈耗油估算为 0

当前会话显示 DRY、29°C、High 和真实剩余 30.0 L。原生估算值不可用或油耗关闭时不显示假圈数；有效估算时按燃油/每圈耗油向下取整显示 LAPS

干湿和抓地力高低属于界面阈值分级，具体规则记录在 README，不修改游戏物理。实际接收仍为约 60 Hz：257 帧捕获约 58.72 Hz，间隔中位数 16 ms，序号缺失 0，本地 RTT 中位数 1.51 ms

## 验证

Android assembleDebug 和 lintDebug 通过，0 错误、5 条警告。真实 964 字节包经 Android 解码器验证，兼容 944、420、412、344、268 字节旧包。非有限抓地力、负燃油估算拒绝。环境采集与分段交界独立判断的检查通过

原生燃油圈数、DRY/DAMP/WET、缺失字段、低油量不足一圈等确定性检查通过。实机通过实际缩略图选择参考图样式，并保存 layout=9。明确标注“演示”的实机流覆盖 12 LAPS、干地、高抓地力、半湿冷热胎、湿地低抓地力、缺失环境及旧包、维修区进入和退出恢复。字体、轮胎色条及燃油条以原始像素检查

实际真实数据截图为 artifacts/reference-final-live.png，复刻显示检查保存在 artifacts/reference-0.7。演示流的湿地检查不代表在真实雨天赛道驾驶测试，燃油估算未做多圈续航准确度验证。测试结束恢复真实桥接可见终端
