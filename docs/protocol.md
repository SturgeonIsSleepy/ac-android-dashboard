# 遥测与后视图协议 0.9.0

桥接监听 IPv4 UDP 9876，全部数值使用小端字节序。手机每秒订阅一次，5 秒无订阅则移除端点。手机连接 UDP socket 到指定电脑及端口，限制接收来源

所有包开头为 32 位 magic `0x31464341`，即 ASCII `ACF1`，接着为 32 位类型

## 遥测包

类型 1，当前固定 1032 字节。Android 解码器也接受旧版 268、344、412、420、944、964 和 1028 字节帧

依序为：magic、类型、序号、地图 ID、状态、原始挡位、转速、最高转速，以上均为 int32

随后为三个 float32：车速 km/h、燃油 L、最大燃油 L

随后为七个 int32：本圈毫秒、上一圈毫秒、最佳圈毫秒、完成圈数、维修区位标记、驶离赛道轮数、旗号

随后为 17 个 float32：游戏圈差、位置 X、位置 Z、车身 heading、四个胎芯温度、四个胎压、五个游戏原始车损值

前 268 字节最后为各 64 字节的 UTF-8 赛道名称和车辆名称，零结尾补齐

0.2 扩展：偏移 268 为四个 float32 轮胎健康信号；284 为当前分段索引、上一分段毫秒、赛道分段数量三个 int32；296 为 float32 归一化赛道进度；300 为 int32 DRS 状态（位 1 支持、位 2 可用、位 4 开启）；304 为 int32 路书数量（0–3）；308 起为三组 int32 弯向（-1 左、1 右）、int32 弯级（0–6）、float32 距离，空组距离为 -1

0.3 扩展：偏移 344 为 int32 实际排名；348 为 64 字节 UTF-8 实际车手昵称，缺少昵称时使用名与姓。没有此扩展时车手栏使用车辆名、排名显示占位符

0.4 扩展：偏移 412 为 int32 仪表量程最高 RPM，416 为 float32 到下一 DRS 开启线的米数。-1 表示未知、没有 DRS 或区间内没有开启资格；游戏报告可用或开启时为 0。发动机红线仍取前缀偏移 28 的最高 RPM，不能与仪表量程混用

0.5 扩展（0.6 沿用）：420 为 int32 参与车辆数；424 为 float32 维修区真实限速，0 未知；428 为 int32 分段记录同步标志，1 有效。432 起为 64 个 int32 个人各段最快毫秒，688 起为 64 个 int32 全场各段最快毫秒，0 未设置。参与车辆数在采集信息缺失时回退共享内存车辆数，不编造全场记录

CSP 只读应用约 20 Hz 输出比赛记录，桥接约 60 Hz 发送主遥测；实际车速、挡位与转速继续直接来自共享内存，不等待文件更新。采集数据必须匹配当前车辆、赛道、完成圈数与当前分段，且文件足够新，防止交界处用新纪录提前覆盖旧纪录。未完成的文件写入忽略

0.7 扩展：944 为 float32 实际 RoadTemp（°C），948 为 float32 roadGrip，952 为 float32 rainWetness，956 为 float32 rainWater，后三者 -1 未知、正常为 0 到 1；960 为 float32 fuelPerLap（L/圈），0 未知或油耗关闭。燃油圈数不直接发送，由手机以实际燃油除以 AC 估算值向下取整。环境数据有效性与分段切换阶段分开判断；新包为 964 字节，仍不等待 20 Hz 文件更新即可发送主遥测

0.8 扩展：964 起为 64 字节 UTF-8 当前轮胎配方名称，来自实际 Graphics.TyreCompound，零结尾补齐，新包为 1028 字节。旧包缺少配方时显示占位。阶段切换由手机结合维修区位标记和完成圈数判断，不增加延迟或等待额外文件

0.8.1 扩展：1028 为 float32 赛道长度（米），优先实际 StaticInfo.TrackSPlineLength，回退真实 AI 路线长度，0 未知。结合已有归一化赛道位置得到距终点距离，供出场圈最后 300 m 的绿条使用。旧包缺少长度时绿条不虚构接近程度

状态低 8 位沿用 AC：0 未运行、1 回放、2 实时、3 暂停。位 256 代表合成演示数据，显示端固定标注“演示”

维修区位标记：位 1 是 `IsInPit`，位 2 是 `IsInPitLane`

## 路线包

类型 2，头部五个 int32：magic、类型、地图 ID、点数、是否闭合。随后依次为各点 X、Z float32，最多 128 点，整包不超过 1044 字节

地图 ID 根据赛道及布局计算。点数 0 表示没有可用路线。每次订阅重发，丢包后自动补回。Android 保留地图数据用于诊断，当前指引页直接绘制遥测中的路书队列

## 订阅与 RTT

类型 3，当前 84 字节：magic、类型、手机单调时钟纳秒 int64；随后三个 int64 为 RTT 毫秒、累计收到遥测数、累计序号丢帧数；三个 int32 为 View 宽、高、display ID；最后 32 字节 UTF-8 设备型号，零结尾补齐。桥接仍接受旧 16 字节订阅

电脑返回前 16 字节并把类型改为 4。手机以自己的单调时钟计算往返时间，无需校时。RTT 在电脑终端显示，不把它当成单向或完整显示延时

遥测序号避免旧包回退，桥接重启后前一流超过 1 秒未更新就接受新序号。界面显示使用手机接收时间，250 ms 超时后隐藏过期驾驶数据

## 0.8.2 有线与无线

TCP 9877 使用四字节 little-endian int32 包长度，再跟原 ACF1 包体。主遥测、路线与 RTT 回包保持原类型和内容。USB 通过 ADB reverse 将手机 127.0.0.1:9877 接到电脑的 TCP 9877，桥接只保留最新待发送帧，不为慢客户端积累无限旧帧

USB 订阅为 92 字节，前 84 字节保持兼容，偏移 84 增加 int64 无线 RTT 毫秒，-1 表示未测到或超时。无线 TCP 继续使用 84 字节订阅，UDP 9876 保留旧协议

类型 7 为 16 字节的无线 RTT 探测，magic、类型与手机单调时钟纳秒。电脑回类型 4，但不将探测端加入遥测订阅。USB 连接期间手机约每秒探测一次无线，三秒未收到有效应答则显示未知。电脑显示的有线与无线数值均为往返延时，不是单向或屏幕完整延时

连接顺序为 USB → 无线 TCP → 旧 UDP。无线连接期间探测 USB 通道，通道出现后切换；USB 断开后重新选择。接收线程使用代次与 socket 所有权，旧线程退出不会关闭新连接

## 0.9.0 后视图

TCP 后视图订阅保留 96 字节类型 3 格式，前 92 字节含无线 RTT，偏移 92 为 int32 镜面选择：0 仪表、1 左、2 中、3 右。当前客户端发送 100 字节订阅，偏移 96 增加 int32 配置能力标记，值为 1 时接收后视镜配置。镜面选择变化时立即重新发送订阅。96、92、84 和 16 字节旧订阅继续支持，旧格式不接收类型 8 配置包或类型 10 状态包；96 字节客户端仍可按选择接收后视图，92 字节及更早客户端仅接收仪表数据

类型 6 为变长后视帧，magic 和类型之后是 int32 镜面选择、int32 图像序号，偏移 16 起为 JPEG。1024 × 576 图像，压缩包体上限 512016 字节，仅通过 TCP 发送。UDP 9876 不承载图像。当前镜面采集为单一选择，多个 TCP 客户端选择不同镜面时，按连接列表中最后一个有效且镜面选择非 0 的客户端决定，即后连接客户端优先，已有连接重新订阅不会改变优先顺序；当前产品主要面向单台手机

图像在采集应用自己的目录中以临时文件原子替换发布。电脑校验图像文件是否在选择之后产生、更新时间是否超过一秒、JPEG 边界及编码长度，再以 JPEG 84 重编码降低传输带宽。每个发送线程只持有最新待发图像，不积累旧图队列。Android 在接收线程解码，核对所选镜面，超过 500 ms 隐藏旧图

CSP 采集心跳包含选择及 UTC 秒，每半秒刷新，超过三秒没有有效心跳则释放后视渲染资源。主遥测的共享内存路径、格式和约 60 Hz 节奏保持兼容

## 0.9.0 后视镜配置

类型 8 为 84 字节完整配置，仅通过 TCP 发送给 100 字节订阅且配置能力标记为 1 的客户端。偏移 0 是 magic，4 是类型 8，8 是 int32 修订号；偏移 12 起为 18 个 float32，按左、中、右顺序各六个字段，字段按以下索引排列：

- 0：垂直 FOV，20° 到 100°，默认 50°
- 1：水平朝向，−60° 到 60°，正值向车辆右侧，左、中、右默认 −10.2°、0°、10.2°
- 2：俯仰，−35° 到 35°，正值抬头，默认 0°
- 3：左右偏移，−2 m 到 2 m，正值沿车辆坐标右移，默认 0 m
- 4：高度偏移，−1 m 到 1 m，正值沿车辆坐标升高，默认 0 m
- 5：前后偏移，−3 m 到 3 m，正值沿车辆坐标前移，默认 0 m

连接后发送当前完整配置。电脑终端或手机修改参数后，桥接生成新修订号并将完整配置发送给支持的客户端。修订号属于本次桥接进程，重启后从 1 开始，不能用它跨进程排序。Android 拒绝长度、magic、类型错误，以及任何非有限或超出字段范围的配置包

类型 9 为 20 字节配置命令：magic、类型 9、镜面选择 int32、字段索引 int32、数值 float32，依次位于偏移 0、4、8、12、16。镜面选择只能为 1、2、3。字段 0 到 5 修改对应参数，桥接拒绝 NaN 与 Infinity，并将有限越界数值限制到该字段范围；字段 6 恢复所选镜默认值，此时最后的 float32 不参与计算。命令仅在该 TCP 连接已用能力标记 1 订阅之后接受，不经 UDP 发送

类型 10 为 12 字节配置读写状态包：偏移 0 为 magic，4 为类型 10，8 为 int32 状态，0 表示正常，1 表示桥接持久化配置文件读写失败。它与类型 8 一样仅发送给配置能力标记为 1 的 TCP 客户端。保存失败时回滚到修改前的六参数，再发布带新修订号的类型 8 和失败状态，客户端以返回的配置为准；启动读取失败时使用默认参数并发布状态 1。错误不会中断连接与遥测。解除文件占用或目录权限限制后，下一次成功保存发布状态 0，清除错误提示。状态包保持独立，类型 8 长度仍为 84 字节

配置在桥接 EXE 旁持久化为 `mirror-settings.txt`，每行 `镜面选择=FOV,水平朝向,俯仰,左右偏移,高度偏移,前后偏移`，浮点数采用小数点格式。保存先写临时文件再原子替换，随后将完整配置以相同方式同步到 Lua 应用自己的 `mirror-config.txt`。采集端按当前镜面读取设置，并在 `mirror-status.txt` 输出实际使用的 FOV 和六参数。配置作用于镜面模型定位后的独立后视相机，左右默认视点稍后移、外移，中镜独立场景排除本车座舱但保留其他车辆
